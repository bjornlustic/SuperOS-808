▶Rhythm Track

A track stores the STEP-button slot for each measure, not the variation — the BASIC VARIATION switch is applied live at playback, exactly as on the stock machine. 12 tracks, 64 measures each. Click a measure to cycle its pattern.

▶Panel Calibration

The rotary switches reach the CPU through a diode encoder, and its truth table had to be read off a 1981 scan — good enough to boot, not good enough to trust. This records what each position actually reads on your machine and writes the table into the 808. Everything it needs (step keys, CLEAR, transport) is unambiguous, so it works on a device that has never been calibrated.
